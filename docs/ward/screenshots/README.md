# Скриншоты Ward

Картинки для галереи «Что умеет Ward» в [README.md](../../../README.md) и для заметок о выпуске
([changes/](../../../changes/README.md)). PNG, до 300 КБ, окно Ward с темой по умолчанию, без
личных данных (токенов, адресов почты, путей с именем пользователя, чужих карточек). Ширина
окна около 1200–1400 точек; лишнее обрезать.

## Ожидаемые файлы

| Файл | Что на скриншоте |
| --- | --- |
| `chimney.png` | Вкладка, привязанная к карточке Chimney: чип карточки со статусом в строке вкладки и в футере агента; можно рядом окно запуска агента по карточке (Ctrl+Alt+N). |
| `agent-exit-running.png` | Картинка к заметке `changes/agent-exit-running.md`: вкладка, где агент запускался из профиля шелла и уже вышел, — строка вкладки без состояния Running, в полосе внимания счётчик Running без этого агента. |
| `whats-new.png` | Окно «Что нового» после обновления: разделы «Новое»/«Улучшения» с картинкой сверху и заметками. |
