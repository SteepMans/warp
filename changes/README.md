# Заметки о выпуске Ward

Из файлов этой папки собирается окно «Что нового», которое Ward показывает при первом запуске
новой версии. CI берёт фрагменты, добавленные или изменённые с прошлого выпуска
(`script/windows/publish_s3.ps1`), и выкладывает их картинки рядом с установщиком.

Каждый PR, который меняет что-то видимое пользователю Ward, добавляет один файл
`changes/<короткое-имя>.md`:

```markdown
---
section: new
image: docs/ward/screenshots/agents-overview.png
---
## Обзор всех агентов в одном окне

Ctrl+Alt+W или кнопка в заголовке открывают карточки всех агентов: сначала те, кто ждёт
ответа. Клик по карточке переключает на вкладку агента.
```

## Поля

- `section` — раздел окна: `new` (Новое), `improved` (Улучшения) или `fixed` (Исправления).
- `image` — картинка к изменению, путь от корня репозитория. Обязательна для всего, что видно
  на экране: скриншот нового окна, кнопки, настройки. Картинки лежат в `docs/ward/screenshots/`,
  PNG, JPEG, GIF или WebP, до 300 КБ (PNG сжимать, например `pngquant` или `oxipng`).
- `## Заголовок` — коротко, что появилось или изменилось, по-русски.
- Текст — одно–три предложения для пользователя: что изменилось и как этим пользоваться
  (хоткей, где настройка, куда нажать). Можно **жирный** и `код` для того, что пользователь
  вводит сам.

## Правила

- Пишем для пользователя, а не для разработчика: простой русский, без имён модулей, файлов,
  функций и флагов. Идентификаторы — только если пользователь их сам вводит (`claude --resume`).
- Одно изменение — один файл. Не дублируем то, что уже описано в другом фрагменте.
- Без фрагмента: документация, CI, рефакторинг, тесты, форматирование — всё, чего пользователь
  не заметит.
- Уже вышедшие фрагменты не правим: изменённый файл попадёт в следующий выпуск ещё раз. Удалять
  старые фрагменты можно.
- Окно «Что нового» показывает одну картинку — первую в выпуске, к остальным заметкам
  добавляется ссылка «Посмотреть картинку».
