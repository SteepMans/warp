## Ward сам ставит обновление, когда никому не мешает

Скачанное обновление больше не ждёт кнопки «Install and restart». Ward ставит его сам и
возвращается с теми же вкладками, когда никто не будет потревожен: 15 минут не было ввода ни в
одном окне Ward, ни в одной вкладке не идёт команда и ни один агент не на середине хода. Агент,
который закончил ход и ждёт ответа, не мешает: его сессия вернётся через `--resume`. Перед
перезапуском Ward выключает приём новых задач (**Take tasks**) и включает его снова после
запуска новой версии; если приём был выключен вами, он так и останется выключенным.

Переключатель **Install updates automatically** в Settings → Updates включён по умолчанию. Пока
обновление ждёт, страница пишет почему, например «Waiting: agent session #4704 is working» или
«Waiting: you are using Ward». Если Ward установлен для всех пользователей, установщику нужны
права администратора, и обновление по-прежнему ставится кнопкой «Install and restart».
