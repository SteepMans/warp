## Ward берёт задачи у сервиса агентов

В Settings → Third party CLI agents появился раздел **Agents worker**: вставьте ключ
подключения, и Ward будет сам принимать задачи, открывать вкладку с Claude Code или Codex в
отдельной копии репозитория и сообщать сервису о ходе работы. Переключатель **Take tasks**
ставит приём новых задач на паузу.
