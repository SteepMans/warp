## Настройки, MCP и скиллы приезжают на машину сами

Ward забирает у сервиса агентов профиль машины и раскладывает его сам: серверы MCP, настройки
Claude Code, общие скиллы и путь к хранилищу заметок. Свои записи Ward помечает и меняет только
их — ваши собственные настройки остаются как были, а когда ключ подключения убирают, Ward свои
записи снимает. DNS-прокси просит права администратора один раз: не дали — машина помечается
«без прокси» и не берёт задачи, которым он нужен. Версия профиля, результат по каждой части и
проверка прокси видны в Settings → Third party CLI agents → Agents worker.
