## Каждая восстановленная вкладка открывает свой диалог

Если в одной папке проекта было открыто несколько вкладок с разными диалогами Claude Code, после
перезапуска Ward все они могли открыть один и тот же диалог: хук профиля шелла, который
запускает агента в папке проекта, срабатывал в каждой восстановленной вкладке. Теперь Ward
помечает такую вкладку её собственной сессией (`WARD_RESUME_SESSION`), хук её пропускает, и
каждая вкладка продолжает свой диалог.
