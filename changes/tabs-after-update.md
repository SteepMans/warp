## Вкладки возвращаются после обновления

Раньше после кнопки «Update Ward» приложение запускалось с одним пустым окном и все вкладки
пропадали. Теперь Ward перед таким перезапуском запоминает открытые вкладки и возвращает их:
каталог, заголовок, оболочку, а вкладкам с Claude Code — команду `claude --resume`, так что
сессию агента можно продолжить. Возвращается по одной панели на вкладку, без истории блоков.
